# Leading Without a Map

**Interactive leadership learning prototype (Version 7.6.1)**

A browser-based companion to the proposed *Leading Without a Map: Practical Leadership Development for Newly Promoted Supervisors* program at fictional Maple Hall Dining.

The instructional proposal combines five one-hour facilitated sessions (in person or via Zoom) with five online learning modules. This prototype includes guided workplace decisions, feedback, and written reflections focused on transitioning from coworker to supervisor, communication and delegation, diagnosing operational problems, feedback, and conflict resolution.

**Launch:** After GitHub Pages is enabled for the `main` branch at `/(root)`, open: https://rstenlund1.github.io/leading-without-a-map-demo/

**Offline use:** Download `index.html` and open it in a browser; the interactive content is self-contained.

**Data and facilitation:** Progress and responses are stored locally in the learner's browser, not uploaded to a server. The prototype does **not** give instructors centralized access to learner answers. If used in the proposed hybrid course, written reflections should be submitted through the institution's learning management system, such as Canvas. Group adoption, assessment practices, and accessibility review remain subject to instructor and team approval.

This is a supplemental demonstration of the instructional approach, **not a replacement for the collaborative program plan**.
